# Happy Headlines

Semester project for the **Development of Large Systems** course.

Happy Headlines is a global positive-news platform. Publishers create and publish articles, while readers can read, comment, and subscribe to a personalised newsletter.

## Current iteration

The first iteration focuses exclusively on architecture. No application code or technology choices have been added yet.

Planned architecture deliverables:

- C4 System Context diagram
- C4 Container diagram
